工具
====

咱们 GIS 如果出来工作，其实偏工科。

制图一般是工学学位，GIS 一般是理学学位，但是出来干活的话，就当咱们是工科吧。工科与理科最大的区别是：注重实际应用，也就是，我们做的是要给人用的，不是只发个论文指导别人去做东西（搞科研的是这一套，当然不完全是，也可能是根据数据分析出一些结论）。所以，需要结合各种工具，把数据展示给人看，给人用。

这部分是介绍一些入行需要了解的工具的，这部分只是做介绍，不是教程，会给出一些资源，大家需要自己看看，自己去了解。有一些是可以速通的，比如docker，我写了，有些工具是没法速通的，比如 Arcgis QGis FME 等等工具，这种还是老老实实去学一下，现在遍地是资源，想学点东西不算特别难找。 

MarkDown 版本中有一节没有内容的科学上网，这里删掉了，想学的自然能找到办法，试试多读下 :ref:`information` 。其实大部分时候没必要科学上网，一来很多油管上的教育视频B站有搬运，二来有很多镜像网站，自己搜一下 xxx 镜像站都能用，学习知识的话，基本也能不用科学上网；真的需要的，就当是练习信息检索吧，自己想办法。
