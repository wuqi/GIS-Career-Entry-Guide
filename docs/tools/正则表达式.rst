正则表达式
==========

几乎所有工具软件和程序语言都支持的正则表达式，我推荐看看 `正则表达式30分钟入门教程 <https://deerchao.cn/tutorials/regex/regex.htm>`_ ，看完基本就会使用了。正则表达式并不难，常用的基本也不会特别复杂，不涉及到 unicode 负向零宽断言 等特别复杂的概念。

如果想更深入了解正则表达式的匹配原理、优化方法和使用技巧的话，推荐去看 `精通正则表达式 https://book.douban.com/subject/11589967/>`_ ，这本书翻译的不错，就别折腾原版了。
