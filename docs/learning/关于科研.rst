################
关于科研
################

其实插在这里不算特别合适，但是在其他地方更不合适。还是在这里说一下吧，科研这块我只说点我知道的东西，不一定对，反正是一些经验。

前置条件
==========

科研需要耐心，或者脸皮厚心宽也行，脑子，以及运气，如果你占两条，可以搞；如果都没有，但是家里有钱，也可以；至少要准备读到博士。脑子差或者动手能力差的，最好是酌情考虑是否真的要走这条路，真要走这条路，就要有心理准备，论文没那么好写，博士没那么好毕业。

太内向不适合科研，至少GIS这行不太适合，需要与人打交道的地方很多，太内向很多时候很麻烦，哪怕国外；倒不是喝酒敬酒什么糟粕文化，主要是各种国内外的会议报告啥的，总得跟人打交道，至少你得讲 PPT ，如果面对五十个人就没法讲话，那么酌情考虑换赛道。

现在搞科研的压力很大，非升即走，跟行政人员搞好点关系有时候也有用。

关于钱
========

谈钱很俗，但是还是要说，搞研究最前面那撮人不差钱，非常不差钱，不管是主业做项目的还是做科研的；但是其他的要熬，着急赚钱的话，别搞科研。

关于入门
==========

想搞研究尽量保研或者直博，考研很费精力，而且现在保研的越来越多，考研名额越来越少，所以越早打算越好。

如果有深造的打算（不是单纯的为了逃避就业），尽早了解学校各个导师，早点跟心仪的导师接触，大一下大二上就可以，不用等，老师会根据你的情况制定计划的。如果学校差点，真的想上进，而且脑子不是特别差，问问外校找个好老板跟着干活搞研究也可以，越早越好，好学校的资源比你想的要重要，老师一般也不那么难说话。如果不知道怎么联系外校导师，找本校年轻老师问问。现在能在大学当老师的基本都是好学校出来的，至少人脉比你强，搞不好能交换，别闷着头学，搞科研需要交流需要动手实验的，这也是为什么好学校喜欢本校的，因为人家有些大一大二开始跟着干活读论文，而有些外校进去除了成绩好啥也不会，至少差着一两年经验。

单纯的为了逃避就业考研，那么联系导师同样是越早越好，准备考研的时候就应该准备找导师，而且跟导师沟通时明确说明不想做科研；有老师做项目顺带搞科研，有老师专心搞科研的，老师在乎这个，找错老师两边都挺头疼的。
