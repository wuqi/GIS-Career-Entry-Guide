关于保密
========

差点忘了，必须提一下，记得数据保密

.. attention:: 

   不要随便把手头项目数据给任何人，违法可能真的要坐牢，我有两个师兄师姐因为这个去吃公家饭了。

------

1. **涉密数据的范围与处理**

   - **重力数据**和**地形图数据**：这些数据通常涉及国家秘密，尤其是高精度的重力数据和地形图。根据规定，泄露此类数据可能对国家安全、领土主权和军事防御能力造成严重威胁。
   - **DEM数据**：精度高于30米的DEM数据可能涉密，尤其是涉及国家重要军事设施或战略区域的数据。未经授权，不得随意获取或分发。
   - **遥感数据**：一般情况下，公开获取的遥感数据已经过脱密处理，尤其是国产卫星数据，质量较高且安全性有保障。但仍需注意数据来源的合法性。

2. **地图使用的注意事项**

   - **问题地图**：在论文、PPT或其他公开材料中使用地图时，必须使用自然资源部发布的官方地图，尤其是矢量边界数据。自行绘制或使用未授权的地图可能导致严重的法律问题。
   - **地图标注**：避免在公开场合随意标注高精度地理位置信息，尤其是涉及敏感区域的地图。手机的GPS精度较高，不当使用可能导致信息泄露。

3. **数据分发与共享**
   
   - **数据分发**：未经批准，不得将项目数据提供给任何人，尤其是涉及重力、地形、高精度DEM等敏感数据。即使是内部共享，也需严格遵守保密规定。
   - **数据存储与传输**：涉密数据应存储在符合保密要求的设备中，传输时需使用加密通道，避免通过互联网或未加密的移动存储介质传输。

4. **法律责任与风险**
   
   - **法律责任**：根据《中华人民共和国保守国家秘密法》和《中华人民共和国测绘法》，泄露涉密测绘地理信息将承担法律责任，严重者可能涉及刑事责任。
   - **风险防范**：定期开展保密自查，确保数据存储、使用和传输环节的安全性。对于涉密数据，务必做到“非授权不接触、非必要不使用”。
